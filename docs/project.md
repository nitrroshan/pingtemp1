Person assigns a task
Task Descriptor Creates multiple subtasks need to be done to complete the task.
Role Manager defines multiple roles to handle these task. It creates Agents with required roles.
Agents work in a group to handle the task.


Task Manager 

1. Creates Subtasks from the main task. SubTask can be Research,Action or Planning.
2. Provides description of each task. What problem it will solve. How it needs to be done.
3. Provides the Knowledge required to do the task
4. Provides the tool required to do the task.
5. Determine Prerequisite for each task
6. Determine the sequence tasks need to be done.

Task Manager has the overall view of all the tasks

Role Manager

1. Creates a goup new agents and assigns them role
2. Assigns the task to the agents based on role.
3. Helps Agents to to have required Knowledgebases and tools required to do the task.

Group Manager/ Agent Manager 

1. Has the complete view of Agents 
2. Helps Agents to find the right Agent for help in the task.
3. Handles communication with user.

Goal Manager
1. Overvies Progress of overall task and Goal
2. Provides Feedback on each task that is Completed.
