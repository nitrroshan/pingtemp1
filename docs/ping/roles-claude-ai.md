## **META-PATTERNS ACROSS ROLES**

Looking across all these, certain thinking patterns appear repeatedly:

**Analytical Cluster:** Scientists, engineers, analysts
- Common: Systematic, evidence-based, hypothesis-testing

**Creative Cluster:** Designers, artists, writers
- Common: Divergent, aesthetic-aware, iteration-based

**Strategic Cluster:** Executives, consultants, planners
- Common: Long-term, stakeholder-aware, trade-off evaluation

**Operational Cluster:** Managers, coordinators, trades
- Common: Process-oriented, efficiency-focused, practical

**Interpersonal Cluster:** Counselors, teachers, service
- Common: Empathetic, communication-focused, relationship-aware

**Investigative Cluster:** Detectives, journalists, auditors
- Common: Evidence-gathering, verification-focused, skeptical

The key insight: **Role-specific thinking is a combination of:**
1. **Domain knowledge** (what facts/models apply)
2. **Procedural approach** (what steps to take)
3. **Evaluation criteria** (what counts as good)
4. **Constraints awareness** (what limits exist)
5. **Stakeholder orientation** (who matters)

Each role is essentially a different **configuration** of these five elements.
