# Messages Component

## Overview
The Messages component manages conversation history for AgentWorker, accumulating messages across multiple invocations to provide context for the LangGraph agent.

## Architecture

```
┌─────────────────────────────────────┐
│        Messages Array               │
│                                     │
│  [0] System Message                 │
│      └─ Agent role & instructions   │
│                                     │
│  [1] User Message (input)           │
│  [2] AI Message (response)          │
│  [3] User Message (follow-up)       │
│  [4] AI Message (response)          │
│  [5] User Message (latest)          │
│  ...                                │
└─────────────────────────────────────┘
         │
         ▼
  Passed to agent.invoke()
         │
         ▼
  LangGraph uses for context
```

## Purpose

### Why Maintain Message History?
1. **Context Persistence**: Agent remembers previous interactions
2. **Conversation Flow**: Enables multi-turn dialogues
3. **Reference Resolution**: "it", "that", "the previous one" work correctly
4. **Task Continuity**: Agent can build on previous work

### Example: Without History
```typescript
// First interaction
User: "Create a user API"
Agent: "Here's a user API..."

// Second interaction (no history)
User: "Add authentication to it"
Agent: "Add authentication to what?" ❌
```

### Example: With History
```typescript
// First interaction
messages = [
  { role: 'user', content: 'Create a user API' },
  { role: 'ai', content: 'Here's a user API...' }
]

// Second interaction (with history)
messages = [
  { role: 'user', content: 'Create a user API' },
  { role: 'ai', content: 'Here's a user API...' },
  { role: 'user', content: 'Add authentication to it' }  // "it" resolved
]
Agent: "I'll add authentication to the user API..." ✅
```

## Implementation

### Message Structure
```typescript
interface Message {
  role: 'system' | 'user' | 'ai' | 'tool';
  content: string;
  name?: string;          // Optional message name
  tool_call_id?: string;  // For tool responses
}
```

### Messages Array
```typescript
class AgentWorker {
  private messages: Message[] = [];
  
  constructor(role: string, config: AgentConfig) {
    // Initialize with system message
    this.messages = [{
      role: 'system',
      content: config.systemPrompt || `You are a ${role} agent.`
    }];
  }
}
```

### Adding Messages
```typescript
private async callAgent(input: string, thread_id: string): Promise<any> {
  // Add user message to history
  this.messages.push({
    role: 'user',
    content: input
  });
  
  // Invoke agent with full history
  const response = await this.agent.invoke(
    { messages: this.messages },
    { configurable: { thread_id } }
  );
  
  // Add AI response to history
  this.messages.push({
    role: 'ai',
    content: response.content
  });
  
  return response;
}
```

## Message Types

### 1. System Messages
**Purpose**: Define agent behavior and role

```typescript
{
  role: 'system',
  content: `You are a backend developer agent.
  Your role is to write TypeScript server code.
  Use Express.js and follow REST API best practices.`
}
```

**Characteristics**:
- Usually first message in array
- Not user-generated
- Persistent across conversation
- Defines agent personality/capabilities

### 2. User Messages
**Purpose**: User input/requests

```typescript
{
  role: 'user',
  content: 'Create a user registration endpoint'
}
```

**Characteristics**:
- Human-generated input
- Triggers agent response
- Can reference previous context

### 3. AI Messages
**Purpose**: Agent responses

```typescript
{
  role: 'ai',
  content: 'Here is the user registration endpoint...'
}
```

**Characteristics**:
- Generated by agent
- Contains response to user message
- Can include code, explanations, questions

### 4. Tool Messages
**Purpose**: Tool execution results

```typescript
{
  role: 'tool',
  content: '{"result": "File created successfully"}',
  tool_call_id: 'call_123',
  name: 'create_file'
}
```

**Characteristics**:
- Generated by MCP tools
- Linked to tool calls
- Provides execution results to agent

## Memory Management

### Problem: Unbounded Growth
```typescript
// After 100 interactions
messages.length = 201  // 1 system + 100 user + 100 AI
// Token usage: ~50,000 tokens
// Cost: High
// Latency: Slow
```

### Solution 1: Truncation
Keep only recent N messages:

```typescript
private pruneMessages(): void {
  const MAX_MESSAGES = 20;
  
  if (this.messages.length > MAX_MESSAGES) {
    // Keep system message + recent messages
    this.messages = [
      this.messages[0],  // System message
      ...this.messages.slice(-(MAX_MESSAGES - 1))
    ];
    
    logger.info('Messages pruned', {
      newLength: this.messages.length
    });
  }
}
```

### Solution 2: Sliding Window
Keep system + last N exchanges:

```typescript
private pruneMessages(): void {
  const MAX_EXCHANGES = 10;  // 10 user-AI pairs
  const maxMessages = 1 + (MAX_EXCHANGES * 2);  // System + pairs
  
  if (this.messages.length > maxMessages) {
    const systemMsg = this.messages[0];
    const recentMessages = this.messages.slice(-MAX_EXCHANGES * 2);
    
    this.messages = [systemMsg, ...recentMessages];
  }
}
```

### Solution 3: Summarization
Summarize old context:

```typescript
private async summarizeHistory(): Promise<void> {
  if (this.messages.length <= 20) return;
  
  // Get old messages (except system and recent)
  const systemMsg = this.messages[0];
  const oldMessages = this.messages.slice(1, -10);
  const recentMessages = this.messages.slice(-10);
  
  // Summarize old messages
  const summary = await this.summarizeMessages(oldMessages);
  
  // Replace with summary
  this.messages = [
    systemMsg,
    { role: 'system', content: `Previous conversation summary: ${summary}` },
    ...recentMessages
  ];
}

private async summarizeMessages(messages: Message[]): Promise<string> {
  const summaryPrompt = `Summarize this conversation:\n${
    messages.map(m => `${m.role}: ${m.content}`).join('\n')
  }`;
  
  const response = await this.summaryAgent.invoke(summaryPrompt);
  return response.content;
}
```

### Solution 4: Token-Based Pruning
Prune based on token count:

```typescript
import { encoding_for_model } from 'tiktoken';

private pruneByTokens(): void {
  const MAX_TOKENS = 4000;
  const encoder = encoding_for_model('gpt-4');
  
  let totalTokens = 0;
  const keptMessages: Message[] = [];
  
  // Keep system message
  keptMessages.push(this.messages[0]);
  
  // Add messages from newest to oldest until limit
  for (let i = this.messages.length - 1; i > 0; i--) {
    const tokens = encoder.encode(this.messages[i].content).length;
    
    if (totalTokens + tokens > MAX_TOKENS) break;
    
    totalTokens += tokens;
    keptMessages.unshift(this.messages[i]);
  }
  
  this.messages = keptMessages;
  encoder.free();
}
```

## LangGraph Integration

### How LangGraph Uses Messages

```typescript
const response = await agent.invoke(
  { messages: this.messages },  // Full history passed
  { configurable: { thread_id: '123' } }
);
```

**LangGraph Behavior**:
1. Receives messages array
2. Saves to checkpoint with `thread_id`
3. Processes with context
4. Returns response
5. Checkpoint includes full history

### Checkpoint vs Messages Array

**Two Sources of Truth**:
1. **AgentWorker messages[]**: In-memory history
2. **LangGraph checkpoint**: Persisted history

```typescript
// AgentWorker messages (in-memory)
this.messages = [
  { role: 'system', content: '...' },
  { role: 'user', content: 'Hello' }
];

// LangGraph checkpoint (persisted)
checkpoint[thread_id] = {
  messages: [
    { role: 'system', content: '...' },
    { role: 'user', content: 'Hello' }
  ],
  state: { ... }
};
```

### Synchronization

**Important**: Keep them in sync:

```typescript
private async callAgent(input: string, thread_id: string): Promise<any> {
  // Update in-memory messages
  this.messages.push({ role: 'user', content: input });
  
  // LangGraph updates checkpoint automatically
  const response = await this.agent.invoke(
    { messages: this.messages },
    { configurable: { thread_id } }
  );
  
  // Update in-memory messages with response
  this.messages.push({ role: 'ai', content: response.content });
  
  return response;
}
```

### Checkpoint Recovery

Restore from checkpoint after crash:

```typescript
private async restoreFromCheckpoint(thread_id: string): Promise<void> {
  // Get checkpoint from MemorySaver
  const checkpoint = await this.checkpointer.get({ thread_id });
  
  if (checkpoint?.messages) {
    this.messages = checkpoint.messages;
    logger.info('Messages restored from checkpoint', {
      messageCount: this.messages.length
    });
  }
}
```

## Message Validation

### Validate Structure
```typescript
function validateMessage(msg: Message): void {
  if (!msg.role) {
    throw new Error('Message must have role');
  }
  
  if (!['system', 'user', 'ai', 'tool'].includes(msg.role)) {
    throw new Error(`Invalid role: ${msg.role}`);
  }
  
  if (typeof msg.content !== 'string') {
    throw new Error('Message content must be string');
  }
}
```

### Validate Sequence
```typescript
function validateMessageSequence(messages: Message[]): void {
  if (messages.length === 0) {
    throw new Error('Messages array is empty');
  }
  
  // First message should be system
  if (messages[0].role !== 'system') {
    logger.warn('First message is not system message');
  }
  
  // Check for consecutive user messages
  for (let i = 1; i < messages.length; i++) {
    if (messages[i].role === 'user' && messages[i-1].role === 'user') {
      logger.warn('Consecutive user messages detected', { index: i });
    }
  }
}
```

## Best Practices

### 1. Always Include System Message
```typescript
this.messages = [{
  role: 'system',
  content: config.systemPrompt
}];
```

### 2. Prune Regularly
```typescript
private async callAgent(input: string, thread_id: string): Promise<any> {
  this.pruneMessages();  // Before each invocation
  
  this.messages.push({ role: 'user', content: input });
  const response = await this.agent.invoke(...);
  
  return response;
}
```

### 3. Don't Mutate Messages
```typescript
// ❌ Bad: Mutates existing message
this.messages[5].content = 'Modified';

// ✅ Good: Create new array
this.messages = [...this.messages.slice(0, 5), newMessage];
```

### 4. Log Message Count
```typescript
logger.debug('Invoking agent', {
  messageCount: this.messages.length,
  lastMessage: this.messages[this.messages.length - 1]
});
```

### 5. Clear When Needed
```typescript
reset(): void {
  this.messages = [{
    role: 'system',
    content: this.systemPrompt
  }];
  logger.info('Messages cleared');
}
```

### Test Message Accumulation
```typescript
test('accumulates messages', async () => {
  const worker = new AgentWorker('test', config);
  
  await worker['callAgent']('Hello', '1');

  await worker['callAgent']('World', '1');
```

### Test Pruning
```typescript
test('prunes old messages', () => {
  const worker = new AgentWorker('test', config);
  
  // Add many messages
  for (let i = 0; i < 100; i++) {
    worker['messages'].push({ role: 'user', content: `msg${i}` });
  }
  
  worker['pruneMessages']();
  
  expect(worker['messages'].length).toBeLessThanOrEqual(20);
  expect(worker['messages'][0].role).toBe('system');
});
```
